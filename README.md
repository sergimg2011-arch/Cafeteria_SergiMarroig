# Cafeteria_SergiMarroig

## Descripción

Aplicación de consola en Java para gestionar pedidos en una cafetería. Permite registrar al cliente y al camarero que atiende el pedido, elegir productos de un menú (bebidas y comidas), generar un ticket con los productos seleccionados y aplicar un descuento a un producto concreto mediante un código promocional.

## Requisitos

- JDK 17 o superior (o la versión que estés usando en tu proyecto)
- IntelliJ IDEA (recomendado) u otro IDE compatible con Java

## Cómo compilar y ejecutar

1. Clona el repositorio:
   ```
   git clone https://github.com/sergimg2011-arch/Cafeteria_SergiMarroig.git
   ```
2. Abre el proyecto con IntelliJ IDEA.
3. Ejecuta la clase `Main` (botón ▶ o `Shift + F10`).

## Instrucciones de uso

1. Al arrancar, introduce el nombre del cliente y el nombre del camarero.
2. Elige productos del menú escribiendo el número correspondiente. Repite hasta añadir todos los que quieras.
3. Introduce `0` para terminar el pedido.
4. Se mostrará el ticket con el resumen del pedido.
5. Opcionalmente, puedes aplicar un descuento del 10% a uno de los productos introduciendo un código promocional válido.
